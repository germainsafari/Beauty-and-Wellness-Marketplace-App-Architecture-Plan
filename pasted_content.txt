PROMPT 3 — Booking System (Core Booksy Feature)
Build a complete appointment booking system for a beauty & wellness 
marketplace app. It must work in real-time and feel as smooth as Calendly 
meets Booksy.

BOOKING ENGINE:
- Providers set their weekly availability (working hours per day)
- Providers mark holidays, breaks, and blocked slots
- Customers see a real-time calendar showing only open slots
- Slot duration is based on the selected service duration
- Buffer time between appointments (configurable per provider)
- Group bookings (multiple clients, e.g. bridal party)
- Waitlist feature when fully booked

BOOKING FLOW (Customer):
1. Search → Select Provider → View Profile & Portfolio
2. Select Service (with price, duration, description)
3. Pick Date → Pick Time Slot (live updated)
4. Add special notes/requests
5. Deposit or full payment via Stripe
6. Confirmation screen with calendar export (Google Cal / iCal)

REMINDERS:
- 24h reminder (push + SMS)
- 2h reminder (push)
- Post-appointment review prompt (push, 1h after slot end)

CANCELLATION & RESCHEDULE:
- Free cancellation window (configurable: e.g. 24h before)
- Late cancellation fee (held from deposit)
- One free reschedule per booking; second reschedule costs a small fee
- No-show protection: provider marks no-show, deposit kept

PROVIDER DASHBOARD:
- Daily/weekly/monthly calendar view
- Quick block time button
- Revenue per day chart
- Client list with visit history

Build this using React Native with react-native-calendars, Stripe SDK, 
and a clean white + soft purple UI. The calendar should have smooth 
horizontal scrolling between weeks. Time slots should appear as pill-shaped 
buttons — green for available, grey for taken.
